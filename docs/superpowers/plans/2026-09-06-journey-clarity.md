# 전체 동선 명확성 개선 실행 계획

> 기존 전체 구현/MBTI 3번의 후속 개선이다. 사용자가 점검과 수정을 함께 승인했다. 새 디자인 선택·정책 승인을 다시 열지 않는다. 격리 작업공간을 유지하고 commit/push/DB/배포는 하지 않는다.

## 목적과 완료 기준

1. 진입 명확성: 커뮤니티 첫 화면에서 MBTI·방문 맛집·배달 후보 목적을 바로 선택한다. 실제 모임과 아이디어/예정표를 구분하며 막혔을 때 재시도/돌아갈 곳을 제공한다.
2. MBTI 입력 연속성: 내 유형→경험→검토/동의 단계와 다음 행동이 보인다. 반복 경험의 개별 편집은 이전/다음에도 유지한다. 긴 검토는 요약/펼치기로 줄이고 오류와 실제 빈 통계를 구분한다. 저장 전 동의·비공개 원칙은 유지한다.
3. 실제 만남 연결: 이번 주는 단일 신청 흐름만 노출한다. 오늘밤 후속은 원천 확인→후속 열기→반환 ID 화면으로 연결한다. 활성 후속 회차는 홈에서 발견할 수 있다. 보드 첫 만남/비보드 첫 만남의 Day 기준은 바꾸지 않는다.
4. 장애 복귀: 인증 장애 시 보호 내용을 열지 않고 설명·안전한 복귀 경로를 제공한다. API 오류 상태와 쿠키 보존을 유지하며 임의 URL로 보내지 않는다.
