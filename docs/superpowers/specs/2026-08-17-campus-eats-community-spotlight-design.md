# Campus Eats 커뮤니티 대표 노출 디자인

## 승인 근거

- 사용자 승인: 커뮤니티 첫 화면 대표 콘텐츠형인 A안으로 구현한다.
- 구현 범위: 커뮤니티 첫 화면의 Campus Eats 노출을 강화하고, 기존 게시판 바로가기는 그 아래에 유지한다.
- 비범위: 월드컵 대결 방식, Elo 계산식, 원격 DB 저장 계약, 운영 배포는 이번 디자인에서 변경하지 않는다.

## 제품 목표

Campus Eats를 일반 게시판 항목 중 하나처럼 숨기지 않고, 커뮤니티에 들어온 사용자가 첫 화면에서 바로 발견하고 한 번 눌러 시작할 수 있는 대표 참여 콘텐츠로 만든다. 음식 사진, 차별점, 검증된 대진 규모, 시작 버튼이 한 화면에서 이어져야 한다.

## 화면 구조

1. 커뮤니티 상단 가로 메뉴에 `맛집 월드컵 NEW` 바로가기를 노출한다.
2. 메뉴 바로 아래에 음식 사진 두 장을 원본 비율을 해치지 않는 `contain` 방식으로 배치한다.
3. 사진 아래의 짙은 영역에서 다음 순서로 설명한다.
   - `부산대 학생들의 실제 비교`
   - `학교 앞 진짜 1등, 우리가 직접 골라요.`
   - 먹어본 곳끼리 비교하면 개인 취향 순위가 정교해진다는 설명
4. 확인된 고정 수치만 보여준다.
   - `93곳 매장`
   - `94장 대진 카드`
   - `7개 음식 월드컵`
5. 주요 버튼은 `1분 취향 분석 시작`, 보조 버튼은 `전체 순위 보기`로 한다.
6. 돈가스, 피자, 치킨, 정문 커피, 북문 커피, 국밥, 밀면을 가로 스크롤 바로가기로 노출한다.
7. 기존 핫글, 모임 후기, 운영자 피드백, 연애 상담, 연애 코치는 대표 콘텐츠 아래에서 그대로 이어진다.

## 카테고리 계약

| ID | 표시 이름 | 카드 수 |
| --- | --- | ---: |
| `donkatsu` | 돈가스 | 14 |
| `pizza` | 피자 | 12 |
| `chicken` | 치킨 | 14 |
| `coffee-main` | 정문 커피 | 17 |
| `coffee-north` | 북문 커피 | 13 |
| `gukbap` | 국밥 | 16 |
| `milmyeon` | 밀면 | 8 |

- `coffee`라는 통합 표시 이름을 새 화면에 사용하지 않는다.
- 정문 커피와 북문 커피는 서로 다른 URL과 저장 키를 사용하는 별도 월드컵이다.
- 기존 `category=coffee` 링크는 호환을 위해 정문 커피로 해석하되 새 링크에서는 만들지 않는다.

## 데이터와 사진 기준

- 기준 목록: `output/campus-food-tournament-handoff/handoff_manifest.csv`
- 기준 PDF: `output/pdf/부산대_맛집월드컵_대진후보_원본비율_총괄보고.pdf`
- 원본 사진: `output/campus-food-tournament-handoff/original-images/`
- 웹 파생 사진은 자르지 않고 `contain`으로 전체를 보여준다.
- 대표 노출 사진은 특정 매장의 실제 메뉴라고 오인시키지 않는 Campus Eats 미리보기 이미지로 사용한다.
- 사용자 수, 실시간 참여 횟수, 별점, 광고 순위처럼 운영 데이터가 없는 수치는 만들지 않는다.
- 사용자 제공 저해상도 사진 7장과 전체 사진 사용권, 현재 영업 상태는 공개 배포 전 별도 확인 대상으로 남긴다.

## 반응형 및 접근성

- 모바일에서는 사진 두 장을 같은 높이의 2열로 유지하고, CTA는 가로 공간에 따라 1열로 내려간다.
- 데스크톱에서는 사진과 설명을 2열로 배치해 첫 화면에서 대표 콘텐츠와 기존 커뮤니티 진입점을 함께 볼 수 있게 한다.
- 모든 링크는 키보드 포커스 표시와 44px 이상의 터치 높이를 갖는다.
- 이미지 대체 텍스트는 음식과 기능 맥락을 설명하고, 장식 아이콘은 스크린 리더에서 숨긴다.
- 텍스트가 사진 위에 겹치지 않으며, 사진은 버튼이나 배지에 가려지지 않는다.

## 완료 기준

1. 커뮤니티 첫 화면에서 음식 사진과 `맛집 월드컵 NEW`가 스크롤 전 보인다.
2. `1분 취향 분석 시작`은 돈가스 대결로 이동한다.
3. `전체 순위 보기`는 돈가스 지도·개인 순위 화면으로 이동한다.
4. 7개 카테고리 링크가 각자의 정확한 `category` 값으로 이동한다.
5. 정문 커피와 북문 커피가 분리 표시되고 각각 17곳, 13곳으로 열린다.
6. 모바일 390x844와 데스크톱 1440x900에서 잘림, 겹침, 가로 넘침이 없다.
7. 기존 커뮤니티 핫글·후기·피드백·연애 진입점이 사라지지 않는다.
8. 관련 자동 테스트, 타입 검사, 실제 브라우저 클릭 검증이 통과한다.

## 범위 밖 위험

- 현재 데이터는 로컬 fixture이며 원격 production DB 대진이라는 뜻이 아니다.
- 공개 서비스 전 사진 사용권, 저해상도 교체 사진, 매장 영업 상태를 다시 검증해야 한다.
- 학교 전체 통계 저장과 실시간 참여 수는 별도 백엔드 계약이 마련될 때까지 화면에 표시하지 않는다.
