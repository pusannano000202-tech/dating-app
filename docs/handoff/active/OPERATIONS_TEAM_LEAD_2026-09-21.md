## 5. 승인·공유 경계

이번에는 요구사항 문서 commit/push와 지정 Slack 채널 보고만 한다. 유저 브랜치/main 병합, 기능 구현, DB migration 적용, 실제 예약·결제·환불·배포는 하지 않는다. 성준 브랜치의 기존 `vercel.json`에는 해당 브랜치의 Git 자동 배포 비활성 설정이 있다. 새로운 브랜치명에는 자동으로 적용되지 않으므로 분기해 올리기 전에 확인해야 한다. 배포 설정 파일은 이번 문서 작업에서 변경하지 않는다.

기존 미커밋 파일을 이동/삭제/덮어쓰거나 `reset --hard`, `clean`, 강제 push로 맞추지 않는다. 담당 결과를 받을 때에도 최신 branch/HEAD/상태를 다시 확인하고 허용된 변경만 합친다.
