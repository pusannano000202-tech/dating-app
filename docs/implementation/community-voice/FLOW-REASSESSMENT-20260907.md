## 사용자 확정 요구와 변경 제안

### G1. 응원 보이스 — 종목, 팀, 작은 방

확정 요구: LCK·야구·축구 → 팀 → 최대 5명 방. 처음 한 방, 4명까지 추가 방 없음, 5명으로 차면 다음 방 자동 생성. 이용자나 운영자가 경기마다 방을 만드는 일이 필요하지 않아야 한다.

제안 동선: `보이스 → 같이 응원하기 → LCK → T1 → 들어갈 방 고르기 → 참여`.

- 팀은 사용자의 예시이며 현재 리그 전체 명단·경기 일정을 확인했다는 뜻이 아니다. 운영자는 분류·팀 등록/중지와 신고를 관리하고, 개별 방 증설은 시스템이 맡는다.
- 첫 이용자에게는 빈 자리 다섯 개와 “첫 응원 시작하기”, 다른 사람이 있으면 “지금 3명과 같이 응원하기”처럼 실제 상태에 맞는 행동을 보여준다. 인원과 성별 수는 실제 값만 사용한다.
- 권장 방식은 **팀별 상설 입구 + 필요할 때만 미디어 방 연결**이다. 항상 미디어 방까지 열어두는 방식은 운영 자원이 늘고, 경기별로만 여는 방식은 일정 관리와 진입 조건이 다시 필요하다.
- 정원·입장·빈 다음 방 생성은 서버에서 함께 확정한다. 동시 입장으로 6명이 되거나 빈 방 여러 개가 생기면 실패다.
- 빈 방 한 개의 단위는 `(학교, 종목, 팀)`이다. 입장 확정된 좌석이 다섯 개면 다음 대기방 한 개를 확보한다. 미디어 연결 준비 중인 좌석을 이미 말하고 있는 사람으로 세지 않는다. 듣기 참여도 한 자리를 사용한다.
- 연결 준비 좌석과 실제 음성 연결 인원을 구분한다. 준비가 만료된 좌석은 반환하며, 재연결 유예는 기존 정책과 일관되게 유지한다. 유예 중 복귀와 새 참가자의 마지막 자리 경쟁도 검사한다.
- 빈자리가 생긴 기존 방을 우선 추천하지만 이미 참여한 사람을 강제로 합치거나 이동시키지 않는다. 사용 중인 방과 대기방 한 개를 남기며, 정리한 방의 신고 기록은 삭제하지 않는다.
- 경기는 각자 정식 중계로 보고 앱은 음성만 연결한다. 경기 종료 뒤 “같이 게임할래요?”는 별도 자발적 참여이며 친구 자동 추가가 아니다.

완료 기준: 0/4/5/10명, 동시 마지막 자리, 중복 요청, 연결 실패·취소, 재접속, 기존 방 빈자리, 차단·강퇴 재입장, 종료 시 마이크 해제를 실제 DB와 여러 클라이언트에서 검증한다.

### G2. 고민 보이스 — 주제별 익명 1대1

확정 요구: 연애·취업 등 고민 분류에서 익명으로 일대일 대화한다.

제안 동선: `고민 나누기 → 연애/취업 등 선택 → 대화 상대 찾기 → 서로 수락 → 통화`.

- 기존 1대1 대기·상호 수락·나가기·다음 상대·차단·신고와 수동 마이크 권한을 재사용한다.
- 최초 세부 주제는 연애·취업 두 개를 제안하며 서로 다른 서버 큐로 분리한다. 기존 수다·학과 라운지는 보존한다. 차단한 상대와는 차단 해제 전 재매칭하지 않고, 신고만 한 상대는 본인의 신고 검토가 끝날 때까지 다시 연결하지 않는 기본안을 제안한다. 이것이 상대방 전체 서비스 이용을 자동 정지시키는 뜻은 아니다.
- 공개 실명·사진·전화번호 대신 가명을 쓴다. 학과 전체 자동 친구는 만들지 않는다.
- 음성은 실시간으로 상대에게 들린다. 앱의 녹음·영상 저장/송출은 제공하지 않는다. 익명이 목소리까지 변조한다는 뜻은 아니다.
- 다음 상대를 누르면 이전 미디어 연결을 먼저 종료한다. 또래 고민 나눔이며 전문 상담으로 표시하지 않는다.
- 종목별 팀 단계가 필요 없는 고민·수다·학과 라운지에 억지로 스포츠 계층을 넣지 않는다.

완료 기준: 두 기기 상호 수락, 거절·만료·넘기기 경합, 이전 통화 음성 미유출, 신원 미노출, 신고·차단 후 재매칭 제한.

### G3. 모임 — 참여부터, 약속은 함께

확정 요구: “오늘 가볍게”와 “약속 잡고”를 나눈다. 일반 모임은 참가 즉시 채팅에서 시간·날짜·장소를 함께 정한다. 추천 장소를 제공하되 고정 예약으로 오해시키지 않는다.

제안 동선: `모임 → 오늘 가볍게/약속 잡고 → 활동 → 참여하고 대화하기 → 채팅에서 시간·장소 제안 → 약속 확인 → 현재 할 일 안내`.

- 오늘: 게임·러닝·카페 등. 오늘 참여 의사를 모으는 것이지 앱이 임의로 시간을 확정하는 뜻이 아니다.
- 약속 잡고: 배드민턴 복식 등 준비·예약이 필요한 활동. 복식 4명과 같은 콘텐츠 정원은 유지한다.
- 보통의 모임은 방장 승인 대기를 기본값으로 두지 않는다. 학교 범위·정원 확인은 보존한다. 현재 차단은 채팅 메시지 필터 중심이며 참가 차단까지 완성됐다는 근거가 없으므로 목록·참가·채팅·학과 초대/수락의 차단 경계를 별도로 구현·검증한다.
- 최초 모임은 기존처럼 사용자가 열 수 있다. 제안하는 간편 개설은 활동·오늘/약속잡기·정원만 선택하고 시작한다. 일반 모임에도 자동 증설을 도입한다는 뜻은 아니다. 일반 모임에 별도의 공식 운영자 표식·권한을 추가하는 것은 이번 기본안에 포함하지 않는다.
- 채팅 상단에 현재 합의 상태를 고정한다. 시간 제안·장소 제안·참가자 확인을 구분하고 “아직 미정”을 실제 확정처럼 표시하지 않는다.
- 조율 제안: 개설자가 공통 후보를 정리하고 참가자는 각자 참여 가능 여부를 확인한다. 채팅 참여만으로 최종 일정에 동의했다고 처리하지 않으며, 일정이 바뀌면 기존 확인을 무효화하고 다시 확인한다. 모임 채팅 참여와 확정 참석 명단은 별도 상태다. 이 확정 방식은 사용자 확인이 필요한 설계 제안이다.
- 상태 기본안은 `조율 중 → 약속 확정 → 진행/종료`, 별도 `취소/만료`다. 배드민턴 복식은 4명, 가벼운 카페·러닝은 2명 이상 등 콘텐츠별 최소 인원이 같은 후보를 확인해야 약속이 확정된다. 미확인 참가자를 참석 확정에 넣지 않는다. 확정 뒤 신규 참여자는 같은 약속을 직접 수락한다. 약속 시작 전 기존 참석자가 나가 최소 인원에 미달하면 재조율 상태로 되돌리고 알린다. 진행 중 이탈은 실제 참석 상태에 기록하고 이미 시작한 약속을 조율 단계로 되돌리지 않는다. 오늘 모임은 오늘 참여 가능 종료 시각, 약속잡기는 별도 조율 마감 시각을 두며 가짜 행사 시작 시각으로 대신하지 않는다.
- 만화 안내는 별도 장문 설명 페이지보다 현재 상태의 행동 한 가지를 우선 안내한다. 약속 전에는 조율, 모인 뒤에는 활동 진행으로 연결한다.
- 기존 여성끼리 쇼핑·남성끼리 활동·혼합 모임과 콘텐츠는 삭제하지 않는다. 발견용 취향 분류와 실제 성별 참여 정책을 혼동하지 않는다.

완료 기준: 참가와 채팅 권한 동시 확보, 마지막 자리 경쟁, 비참가자 읽기 거부, 탈퇴 후 신규 메시지 접근 차단, 일정 변경·재확인, 새로고침 복구, 실제 진행 안내.

### G4. 익명 만남과 신뢰

확정 요구: 그날 배정받은 재미있는 닉네임으로 모인다. 실제 친구 초대에서 상대를 알아볼 이름을 쓰는 기존 결정은 공개 실명 정책으로 확대하지 않는다.

- 제안: 한국 날짜 기준으로 하루 동안 같은 오늘의 별명을 서버에서 발급하고, 참여한 방에는 당시 별명을 기록한다. 자정이나 새로고침으로 이미 대화하던 사람이 다른 사람처럼 보이지 않게 한다. 방 안 동명이인은 짧은 방 전용 식별 표시로 구분하며 전역 계정 ID를 붙이지 않는다.
- 히어로·판타지 분위기는 살리되 성별만으로 취향을 고정하지 않는 테마 선택을 제안한다. 사용자 예시 캐릭터명·이미지를 상업 사용 가능한 자산으로 확정하지 않는다.
- 내부 계정·신고·차단 연결은 지속한다. 별명이 바뀌어도 제재를 피할 수 없다. 다른 고민방 방문 이력이나 계정 식별자를 참여자에게 공개하지 않는다.
- 학교 인증은 실제 확인 상태만 표시한다. 소득·직업 등 사용자가 요청하지 않은 데이팅 인증 항목을 추가하지 않는다.

완료 기준: 같은 날 별명 유지, 자정 경계·동명이인 구분, 과거 메시지 이름 보존, 신규 방의 공개 개인정보 차단, 신고·차단 지속.

### G5. 학과대항 — 폼보다 팀원 초대

확정 요구: 팀원을 쉽게 초대해 게임·운동에 함께 참여한다. 과 전체를 친구나 팀원으로 자동 등록하지 않는다.

제안 동선: `학과대항 → 게임/운동 고르기 → 인원 자리 보기 → 친구 초대 → 상대 학과 팀 찾기 → 양측 약속 확인`.

## 검토 상태

새 콘텐츠 제안은 사용자의 동선 확인 전이다. 독립 검토의 지적과 실제 복구 검증 결과를 반영한 뒤, 새 구조를 구현하는 범위를 확정한다. 현재 화면의 조회 실패를 새 기능 운영 완료로 보고하지 않는다.

독립 검토 보완 기록: 차단 참가 가드가 이미 있다는 오인을 정정했고, UI 1시간/API 30분 조건 차이, 학과대항 초대 범위, 일일 별명·좌석 상태·조율 상태·확정 참석 기준을 명시했다. 경기 뒤 같이 게임하기는 이번 사용자 발화에 있으므로 자발적 후속 행동으로 유지했다. 신규 전체 기능의 완료 판정은 아니다.

추가 문서 검토에서는 일반 모임의 공식 운영자 표식이 이미 있다는 근거 없는 표현을 제거했고, 최소 인원 이탈에 따른 재조율은 약속 시작 전으로 한정했다. 초기 오류와 복구 후 상태의 시제, 근거 행 번호도 바로잡았다. 원인은 기존 구현 사실과 새 제안을 같은 문장에 섞었던 문서 작성 오류이며, 확인된 현재 사실·새 제안·미검증 상태를 별도 구분하는 방식으로 보완했다.

인증 실행기 독립 검토는 PASS다. 작업공간·로컬 Docker·Windows dotenv 검사 세 지적을 수정하고 독립 focused 7/7 및 문법 검사를 통과했다. 부모는 최종 실행기로 실제 재시작과 브라우저 화면 유지까지 확인했다. 이 검토는 새 콘텐츠 기능이나 운영 출시 승인에 해당하지 않는다.
