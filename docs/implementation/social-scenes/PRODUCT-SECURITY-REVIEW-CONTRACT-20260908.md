# 보이스·보안·홈·학과 대항 점검 계약

기준: 2026-09-08 현재 사용자 요청. 기존 승인된 보이스·친구·모임 경계를 보존한다.

## 목표와 완료 증거

1. 보이스 실제 연결: 기존 LiveKit/대기/수락/퇴장 코드의 구현 여부와 설정·DB·실기기 검증을 분리한다. 이번 안전한 로컬 변경은 확인된 예기치 않은 연결 종료 후 재접속 결함과 회귀 테스트로 제한한다. 실제 통화 완료는 1:1 및 5인 실기기 송수신 증거가 있어야 인정한다.
2. 보안 점검서: 운영자/업장/최고관리자, 일반 앱·의존성, 보이스를 독립적으로 조사한다. 파일·라인, 재현 조건, 영향, 수정 제안, 신뢰도·검증 한계를 기록한다. 확인된 코드 위험을 실제 유출 사고로 단정하지 않는다.
3. 홈: 내 매칭·이어 만남과 내가 참가한 일반 모임의 다음 행동을 먼저 보여준다. 콘텐츠 홍보는 사진·짧은 행동 문구 중심이며 조회 실패와 실제 빈 상태를 섞지 않는다. 디자인 3개 이미지 선택 이후 실제 구현한다.
4. 학과 대항: 종목 선택→팀 정원/팀 이름→팀 생성→친구 초대→수락→상대·일정 확인. 기존 서버 권한과 정원 2~20, 멤버십 확인, 양쪽 확인, 자동 친구 추가 금지를 보존한다. 긴 양식보다 사진과 자리 표시 중심으로 제안한다. 새 실명/사진 공개, 재학 인증 배지를 추가하지 않는다.

## 범위와 금지

- 대상: social-scene-implementation-20260907, codex/social-scene-implementation-20260907, 기준 HEAD be9078565d8e59f73cbc017f3c7b1484996da1c3. 시작 시 staged 0, 기본 `git status --short` 출력 645 entries. untracked 디렉터리를 접은 항목 수이며 파일 개수가 아니다. 이전 변경을 포함한 전체 dirty 통계를 이번 변경량으로 오인하지 않는다.
- 감사는 저장소 전체를 대상으로 위험 표면을 선별하는 1차 점검이지 모든 경로 침투 테스트나 사고 포렌식이 아니다.
- 앱 소스 변경 허용 목록: components/voice/VoiceSessionView.tsx, 최소 보이스 수명주기 helper, 해당 회귀 테스트. 홈·학과 새 디자인은 선택 대기.
- 새 파일: 이 계약, 종합 점검 보고서, 현재 검사 캡처. 기존 artifacts/qa·참고 자료는 유지.
- stage/commit/push, 패키지 설치·자동 audit fix, DB migration 적용, 서비스 가입·비용 지출·키 발급, 원격 권한 변경·배포는 수행하지 않는다.
- 키·토큰·전화번호 등 비밀값을 출력하지 않는다. 환경변수 존재 여부와 공개 가능한 설정 이름만 기록한다.
- 운영자≠업장. 화면 분리만으로 권한 분리를 인정하지 않고 서버와 DB 경계까지 추적한다.

## 검증

- 보이스: 결함 재현 RED→최소 수정 GREEN, 종료·재접속·오래된 콜백·퇴장/언마운트 회귀, 기존 테스트 및 타입 검사.
- UI 점검: 실제 로컬 홈·학과 대항 390×844 및 1440×900, 버튼·폼·가로 넘침 확인. 생성 시안은 구현 캡처가 아니다.
- 보안: 범위별 테스트와 코드 검토 결과를 구분한다. 원격 RLS/배포 환경/실계정/실기기 통화는 별도 미검증으로 남긴다.
