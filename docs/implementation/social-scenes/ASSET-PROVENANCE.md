- `advice.png`: 같은 날짜 ImageGen 제작. 헤드폰을 쓰고 차분하게 대화하는 성인 여성 연출 사진. 실제 회원이 아니다.

- 사진은 캐러셀과 커뮤니티에서 Next Image의 화면 폭별 최적화 요청으로 표시한다. 원본 PNG 파일을 삭제하거나 리사이즈해 원본을 덮어쓰지 않았다.
- LCK/KBO 20개 팀 로고: `team-sources.md`의 공식 자료 및 날짜 참조. 로컬 식별용 검토와 공개 서비스의 상표/이미지 사용 권한 확인을 구분한다.
- 장소 월드컵은 PC방/헬스장/보드게임방 사진 선택 및 외부 검색만 구현했다. 확인된 장소 후보·권리 확인된 매장 사진이 없는 상태에서 실제 투표나 순위를 만들지 않는다.
