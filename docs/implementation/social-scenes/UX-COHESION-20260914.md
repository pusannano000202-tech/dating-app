## 순서와 소유 경계

1. parent: 현재 파일/활성 결정/스크린샷 확인, baseline, 통합 계획, 내 메시지 판별 서버 조사, 공통 사진 metadata 계약, 브라우저 QA·독립 리뷰·보고.
2. home-match: G1 홈 내 모임 및 모임 재개 띠, G3 매칭 진입 표시만. 공유/채팅 컴포넌트 수정 금지.
3. chat: G2 SocialChatDirectory/SocialChatRoomPage/SocialMessenger 및 활동방 어댑터·CSS. 홈/공유/인증/SQL 수정 금지.
4. sharing: G4 공유 UI/helper/개설 결과/안전한 auth return 연계. 기존 금융·DB·다른 worker 파일 수정 금지.

새 공통 API/타입 파일이 필요하면 parent와 합의 후 한 명만 편집한다. 서버 사진 metadata는 현재 권한으로 확인 가능한 방 정보에서만 파생하며 비공개 계정/참가 신청 소개를 노출하지 않는다.
