## 아직 완료가 아닌 것

1. **DB 반영·실제 통화**: 기존 로컬 스택에는 `20260906181225_community_social_integrated.sql`과 이번 신규 SQL이 적용되지 않았다. 새 보이스·학과·친구 출처 API가 준비 오류를 반환하는 상태를 숨기지 않았다. 코드/임베디드 DB 테스트는 실서비스 연결 증거가 아니다.
2. **보이스 제공자 연결**: 서버 전용 `LIVEKIT_URL`, `LIVEKIT_API_KEY`, `LIVEKIT_API_SECRET`, 허용 연결 주소 `LIVEKIT_CONNECT_ORIGINS`, 정리 작업 인증 `VOICE_WORKER_SECRET` 설정과 webhook/정리 worker 구동, 실제 기기 간 송수신·마이크 거부·재연결·다음 상대 전환 검증이 필요하다. 비밀 키를 NEXT_PUBLIC 변수에 넣지 않는다.
3. **장소 월드컵**: PC방·헬스장·보드게임방 사진 탐색과 지도 검색 진입까지다. 실제 후보, 이용 가능한 매장 사진, 투표/순위는 아직 없다. 임의 후보나 가짜 순위를 넣지 않았다.
4. **배달 후보**: 기존 후보 검증 절차를 유지했다. 검증 후보가 충분하지 않아 실제 대결을 열지 못하는 상태다. 쿠팡 제휴·무료 배달·최소주문 금액을 확인 없이 주장하지 않는다.
5. **축구 응원 팀**: 어떤 리그를 대상으로 할지 확정되지 않아 팀·방은 준비 상태다. LCK/KBO 20팀을 축구까지 완전한 전체 스포츠 명단이라고 주장하지 않는다.
6. **이미지·로고 권리**: 실제 회원·매장 사진이 아닌 연출 이미지다. 구단 로고는 공식 식별 자료의 로컬 검토용 사본이며 공개 배포 사용 권리 확인은 별도다. `ASSET-PROVENANCE.md`, `team-sources.md` 참조.
7. **이어 만남의 완전한 비밀 유지**: 공개 화면의 미래 일정 문구는 제거했지만 기존 `public/images/match/five-meeting/` 자산은 URL로 접근할 수 있다. 콘텐츠/이미지 비공개 저장소와 현재 회차 권한 확인까지 적용해야 완전한 비공개라 할 수 있다.
8. **새 학과 친구 초대**: 보내기·본인 수락·만료는 구현했다. 초대 개별 거절·주장 회수 UX는 별도 보완이 남는다. 팀 참여/탈퇴·모집 취소와 초대 취소는 다르다.
9. **전체 내 모임 채팅함**: 현재 일반 모임 탐색 API의 최근 모집 범위에서 참여 모임을 연결한다. 전체 과거·진행 중 채팅방을 빠짐없이 보여주는 개인별 목록 API는 별도 구현이 필요하다.
10. **운영/실계정/로그인**: 기존 로컬 인증 세션으로 화면을 열었다. 신규 3013 로그인 callback은 기존 3010으로 유지되므로 새 로그인 전체 흐름은 미검증이다. 원격 DB·권한·결제/환불·푸시·배포·실기기 검증은 수행하지 않았다.
