## 동작

1. 우리 과 팀 목록 → 빈자리 지도 → 포지션·현재 실력 선택.
2. `한마디로 나 소개하기`를 펼쳐 선택 입력한다. 포부 한마디 80자, 내 장점 120자(Unicode code points). 장점에는 줄바꿈을 허용한다. 비워도 신청할 수 있다.
3. 신청은 승인 대기이며 확정 인원에 포함하지 않는다. 신청자 본인에게 작성 내용과 취소 버튼이 보인다.
4. 해당 팀의 현재 주장은 신청자의 포지션·실력·소개를 함께 읽고 승인/거절한다.
5. 취소·거절 시 저장 소개를 제거하며 재신청은 새 소개를 사용한다. 다른 팀으로 이동할 때 작성 중 소개가 따라가지 않는다.

공개 모집 목록·일반 팀원·상대 팀·초대 미리보기·알림에 소개를 추가하지 않는다. 소개는 공개 프로필이 아니라 별도 private table의 신청 정보다. 현재 학교·학과/주장 권한, 차단·삭제·제재 상태를 조회 시 다시 검사한다. 연락처를 입력하지 말라는 안내를 제공한다.

## 디자인

- 크림 바탕, 코랄 주 행동, 고대비 본문과 큰 빈자리 표기.
- 기존 종목 사진을 재사용하고 종목 공통 이미지임을 표시한다. 실제 팀 사진·인증 표시를 꾸며내지 않는다.
- 상단 중복 제목/받은 초대 영역을 합치고 지도 앞 팀 전환은 접어서 제공한다.
- 축구 지도는 기존 전체 필드 이미지·포지션 좌표를 유지한다. 유니폼은 기존 아이콘 라이브러리의 Shirt, 빈자리는 Plus로 표현한다. 축구 실력은 자리 선택 상세에서 읽으며 상대 비교 화면의 정보는 유지한다.
- 모집 소식의 날짜를 한국 시간 기준 짧은 희망 시각으로 표시한다. 마감 소식의 빈자리 숫자는 모집 중 상태와 구별한다.
