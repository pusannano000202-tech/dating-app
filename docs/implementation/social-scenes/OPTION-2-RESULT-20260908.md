## 증거 수준과 남은 작업

1. **DB 적용:** 신규 파일 `20260907200713_admin_mfa_privacy_boundary.sql`, `20260907201908_home_my_meetups_read.sql`을 포함한 누락 변경을 격리 검수 DB에 적용할 별도 승인이 필요하다. 적용 전 관리자 API는 신규 검증 RPC 부재 시 안전하게 503으로 막힐 수 있다. 직접 DB의 새 차단은 아직 활성화되지 않았다.
2. **보이스 제공자:** `LIVEKIT_URL`, `LIVEKIT_API_KEY`, `LIVEKIT_API_SECRET`, webhook/worker 비밀값과 허용 origin을 서버 비밀 저장소로 연결한다. 비밀값을 채팅이나 `NEXT_PUBLIC_*`에 넣지 않는다. 계정·비용·설정은 별도 승인 범위다.
3. **실행 검증:** 본인 모임 조회→기존 채팅, 팀 생성→초대→수락, 일반 사용자/두 업장/운영자/최고관리자 권한, 실계정 MFA 등록/재로그인/권한 회수 검증.
4. **실기기 통화:** 1:1과 5인 송수신, 권한 거절, 재연결, 다음 상대, 강퇴, 강제종료, webhook 누락/참가자 대조 복구. 현재 제공자 참가자와 DB 불일치 복구·신고 후 이용 제한·보관/파기 운영 정책도 출시 전 남아 있다.
5. **출시:** 운영 DB/환경값/도메인/문자/알림/결제·환불·개인정보 운영 정책과 배포 검증. 이번 로컬 UI 결과로 대신할 수 없다.
