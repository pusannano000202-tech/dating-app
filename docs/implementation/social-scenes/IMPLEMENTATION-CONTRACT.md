# 승인된 전체 UI 동선의 실제 앱 반영

기준: 2026-09-07 최신 사용자 요청. 4175 시안의 9개 여정은 개념 승인됐으며 이번 작업은 별도 Next 앱 작업공간에서 실제 route/component에 반영한다. 기존 로컬 앱을 통째로 시안 코드로 교체하지 않는다.

## 목표·수용 기준

1. 커뮤니티: 사진 편집형 콘텐츠/게시글/보이스의 동등한 입구. 콘텐츠 안에서 방문 음식/MBTI 인물/배달 라이더/장소 사진을 가로 넘기며 고른다. 버튼·키보드·터치 및 선택한 목적지 일치. 기존 게시글·MBTI·맛집 기록과 API 유지.
2. 응원: LCK/야구/축구 사진 장면을 넘겨 선택→리그에 맞는 전체 팀·공식 로고→5인 응원방. LCK/KBO 2026 공식 명단 확인, 팀 코드와 다른 역사 파일명을 표시명으로 오인하지 않음. 실제 인원만 표시, API 미설정은 실패/준비 중이지 가짜 0명 아님. 축구는 리그 범위 미지정이므로 기존 축구 경로 보존 및 준비 상태를 명시하며 임의 특정 리그를 전체로 주장하지 않음.
3. 상담: 연애/취업/익명 수다 사진 장면→이야기할 사람/들어줄 사람 역할→같은 주제·반대 역할의 대기→서로 수락→통화. 다음 상대는 이전 미디어를 정리한 뒤 재대기. 맥동은 대기 상태 또는 실제 음성 입력과 구분, 가짜 음성 입력 표시 금지. 애니메이션 감소 설정 지원. 마이크는 명시 조작 전 열지 않음.
4. 친구·채팅: 카카오톡처럼 친구 목록에서 선택→프로필/1:1 대화, 친구/대화 목록을 명확히 구분. 지인/앱에서 만난 친구 그룹을 관계 출처 근거가 있는 경우에만 표시하고 불명 기록은 미분류. 자동 친구·실명 공개 확대 금지. 기존 수락/차단/숨김/읽음/전송 실패 기능 보존.
5. 학과대항: 모임 안에서 게임·운동 선택→우리 팀 구성/친구 초대→상대 학과팀→약속 확인 진입. 긴 작성폼을 첫 행동으로 강요하지 않고 기존 참가·확정 권한 유지. 팀별 정원과 수락 여부를 실제 상태로 표시.
6. 통합·보존: 기존 매칭/모임/첫 만남 이후 경계를 깨지 않고 위 화면을 연결. 공개 홈에 미래 Day/미션 노출을 추가하지 않는다. 익명·동반 친구·기존 여성/남성/혼합 모임 보존. 일반 모임 즉시 채팅과 배정 매칭 채팅은 합치지 않는다.
