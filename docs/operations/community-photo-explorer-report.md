## 변경한 내용

커뮤니티의 세 가지 정적 바로가기를 하나의 사진 탐색 화면으로 바꿨다. 같은 페이지에서 선택 버튼, 사진, 질문, 설명, 시작 버튼, 색상이 함께 전환된다. 실제 페이지 이동은 시작 버튼에서만 일어난다. 기존 매칭의 사진·포인터 탐색 패턴과 Quantum 색상·모서리·아이콘 체계를 재사용했다.

| 선택 | 사진과 질문 | 시작 버튼의 목적지 |
| --- | --- | --- |
| MBTI 연애 통계 | 대화하는 사람들 · 나는 어떤 MBTI와 잘 맞았을까? | `/community/mbti` |
| 방문 맛집 월드컵 | 돈가스 한 접시 · 학교 앞 맛집, 내 최애는 어디일까? | `/community/campus-eats?mode=battle&category=donkatsu` |

- 사진 3장은 미리 로드하고 전환 시 투명도만 바꾼다. 동작 줄이기 설정에서는 전환 애니메이션을 제거한다.
- 모바일은 사진 위·설명 아래, 데스크톱은 사진·설명을 2열로 배치한다.
- 중복된 큰 맛집/MBTI/배달 카드 제거. 기존 일곱 음식 분류와 지도는 ‘음식별로 바로 고르기’에 보존했다. 커뮤니티 게시판·하단 내비게이션은 유지했다.
- 사진은 기존 로컬 연출 자산이다. 실제 회원·매장·배달 후보의 증거로 사용하지 않는다.

- 세 선택 버튼: 해당 사진·제목·설명·CTA가 동시 변경, 커뮤니티 URL 유지.
- 이전·다음 버튼: 순환 전환.
- 사진 가로 드래그: 배달 → MBTI 순환. 25px 짧은 이동과 100px 세로 포인터 드래그는 선택을 바꾸지 않음.
- 선택 버튼 ArrowRight: MBTI → 방문 맛집, 키보드 초점도 해당 버튼으로 이동. End → 배달, Home → MBTI.
- 사진 초점에서 ArrowRight/End/Home: 방문 → 배달 → MBTI. 사진 초점 유지, 어두운/밝은 이중 초점 테두리 확인.
- CTA 초점에서 ArrowRight: 선택 및 링크 목적지 유지(아래 수정 사항의 재검증).
- 실제 CTA 세 개를 눌러 도착 페이지 확인, 커뮤니티 링크로 복귀.
  - MBTI: ‘내 MBTI는 무엇인가요?’ 도착. 서비스 연결 불가 표시는 기존 로컬 DB 미연결 조건.
  - 방문: 기존 기기 저장 월드컵의 결과 화면이 복원됨. 사용자 저장 데이터는 지우지 않음.

## 발견한 문제와 수정 내용

1. 상단 MBTI 선택처럼 보이는 강조와 하단의 고정 돈가스 화면이 불일치했다. 단일 선택 상태로 사진·내용·CTA를 묶었다.
2. 독립 검수에서 CTA의 방향키가 상위 이벤트로 전파되어 목적지가 바뀌는 문제 발견. 실제 브라우저 재현 후 키 처리를 선택 영역과 사진에만 한정했다. 같은 재현에서 MBTI 링크가 유지됨을 확인했다.
3. 랜딩이 개인 이력을 읽지 않는데 특정 MBTI 횟수가 내 기록처럼 보일 수 있었다. 일반적인 여러 경험 안내로 바꾸고, 자기보고 통계/비과학적 예측 고지를 CTA 이전 본문에도 넣었다.
4. 밝은 사진에서 흰 초점 테두리가 묻힐 수 있어 밝고 어두운 이중 대비 테두리로 변경했다.
5. 상단 설명의 글자 대비가 낮아 기존의 흐린 색상을 더 진한 본문 색상으로 교체했다.

## 남은 위험 또는 미검증 사항

- 실제 휴대폰 터치, 멀티터치·운영체제 pointercancel, 스크린리더 음성, OS 동작 줄이기 설정의 실기기 검증은 미실시. 코드와 자동 검사/브라우저 포인터 증거를 실기기 증거로 간주하지 않는다.
- MBTI 실계정 저장·집계, 배달 후보 조회/비교는 로컬 DB 미연결로 이번에 검증하지 못했다. 이번 작업은 API·DB·인증을 변경하지 않는다.
- 운영에서 맛집/배달 경로는 `NEXT_PUBLIC_COMMUNITY_ENABLED=true`와 `NEXT_PUBLIC_CAMPUS_EATS_ENABLED=true`가 모두 필요하다. 커뮤니티만 열고 맛집 플래그를 닫으면 기존과 동일하게 맛집 목적지는 404가 된다. 원격 설정 조합과 배포는 미검증이며 이번 작업에서 변경하지 않았다.
- 재사용한 사진의 원본 생성/권리 기록은 인벤토리상 HOLD다. 연출 이미지 표시는 공개 권리 승인을 대신하지 않는다. 공개 배포 전 승인 또는 승인 자산 교체 필요.
- 외부 전송, stage, commit, push, migration, 실제 결제, 배포, Docker 초기화는 하지 않았다.
