# 방문 맛집 월드컵 진입 오류 수정 — 2026-09-06

판정: 로컬 수정 및 브라우저 검증 완료. 운영 배포는 하지 않음.

## 변경한 내용

- 일반 방문 맛집 입구는 `/community/campus-eats?mode=choose`로 통일했다. 돈가스·피자·치킨·정문 커피·북문 커피·국밥·밀면 7종을 먼저 선택한다.
- 선택한 음식은 `mode=setup`으로 새 대진 준비 화면에 진입한다. 완료 결과나 진행 중 대결을 자동으로 열지 않는다.
- 저장된 월드컵이 있다면 `지난 결과 보기` 또는 `진행 중인 월드컵 이어하기`를 별도로 제공한다. 단순 진입은 저장된 대결과 누적 취향 점수를 삭제하지 않는다.
- `mode=battle`은 명시적 복원, `mode=map`은 지도, `mode=setup`은 준비 상태로 구분하여 새로고침에도 유지한다.
- 최초 저장 상태를 읽기 전에는 공통 준비 안내를 표시해 기본 돈가스 화면이 순간적으로 노출되지 않도록 했다.

## 발견한 문제와 수정 내용

원인 추적과 독립 리뷰를 함께 적용했다.

1. 공통 링크의 `category=donkatsu&mode=battle` 고정 → 음식 선택 화면으로 변경.
2. 저장 세션이 있으면 완료 결과까지 자동 복원 → 명시적인 새 준비/복원 모드로 분리.
3. 카테고리가 바뀌는 동안 이전 카테고리 상태를 저장하거나 동일 후보 API 응답에 재복원될 수 있음 → 카테고리별 hydration 범위를 확인한 뒤에만 저장/URL 쓰기 수행.
4. 준비 화면에 방문한 진행 중 세션은 명시적 battle 링크도 준비 화면으로 열림 → 저장된 화면 값보다 명시적 battle 의도를 우선함.
5. 지도에서 음식 종류를 왕복하면 오래된 진입 의도로 준비 화면이 다시 열림 → 지도 내 음식/학교 변경 시 의도를 map으로 갱신.
6. 안내 완료 후 과거 결과가 열릴 수 있음 → 안내 종료 후 요청한 화면으로 이동하도록 보존.
