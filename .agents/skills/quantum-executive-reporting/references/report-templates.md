```text
- 다른 작업방에 지시 금지
- 사용자에게 직접 질문 금지
- 지정되지 않은 파일·Git·배포 작업 금지

```

```text
- 이미지·화면이 있으면 절대 경로와 대표 이미지 2~4개
- 없으면 "이미지 없음"

쉬운 설명: 최대 3개
1.
2.
3.

추천안:

- stage / commit / push / migration / production 여부

- 파일·이미지·출처·수치·테스트
```

## 3. 대표실 사용자 보고

```text
[현재 단계]
한 문장으로 어디까지 왔는지 설명

[눈으로 볼 결과]
대표 이미지 2~4개를 실제로 표시

[쉽게 말하면]
1. 핵심
2. 핵심
3. 핵심

[대표실 추천]
추천 1개와 사용자 관점 이유

[결정할 것]
1. 최대 3개

[승인하면 다음]
승인 후 움직일 작업방과 결과

[변경·위험]
코드, 문서, Git, production 상태
```

## 4. 현재 할 일이 없는 방의 재보고

```text
상태: 해당 없음
한 줄 결론: 현재 Gate에서는 이 작업방이 움직일 이유가 없습니다.
최근 완료한 일: 있으면 한 문장과 증거 경로
대기 이유: 어떤 사용자 승인이 있어야 열리는지
변경: 없음
```
